Responsive Image Gallery

A responsive and interactive image gallery built using HTML, CSS, and JavaScript. The project displays images in a responsive grid, supports category-based filtering, and allows users to view images in a lightbox with next and previous navigation.

✨ Features

Responsive Design: Adapts to desktop, tablet, and mobile screen sizes.

Category Filters: Filter images by Nature, City, and Animals.

Interactive Lightbox: View images in a larger overlay.

Image Navigation: Navigate between images using next and previous buttons.

Keyboard Controls: Use arrow keys to navigate and Escape to close the lightbox.

Hover Effects: Smooth transitions and image zoom effects.

Separate Image Data: Manage image titles, categories, and file paths in images.js.

Organized Image Folders: Store images in separate folders by category.

Accessibility: Includes descriptive image alt text and keyboard interaction.

🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES Modules)

DOM Manipulation
